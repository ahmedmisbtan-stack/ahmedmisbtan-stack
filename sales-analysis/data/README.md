# Data

The CSV dataset used for this practice project is generated for portfolio learning purposes.

Expected file:

`sales_analysis_dataset.csv`

Columns:

| Column | Description |
|---|---|
| Date | Transaction date |
| City | Customer city |
| Category | Product category |
| Product | Product name |
| Units | Units sold |
| Unit_Price_EGP | Unit price in Egyptian pounds |
| Revenue_EGP | Transaction revenue in Egyptian pounds |

The dataset is intentionally small so the analysis can be understood and reproduced easily.
