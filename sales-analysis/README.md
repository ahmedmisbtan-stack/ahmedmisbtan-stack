# Sales Analysis

A small sales analysis project built as part of my Data Analyst portfolio.

## Goal

Analyze sales data to understand revenue, units sold, average order value, and the best-performing products and categories.

## Tools

- Python
- Pandas
- Excel / CSV
- Basic data analysis

## Dataset

The dataset contains sales transactions with:

- Date
- City
- Category
- Product
- Units
- Unit price
- Revenue

## Initial findings

Using the current practice dataset:

- Total revenue: **80,270 EGP**
- Units sold: **247**
- Transactions: **25**
- Average transaction value: **3,211 EGP**
- Top category by revenue: **Electronics**
- Top product by revenue: **Wireless Mouse**

> These numbers come from the practice dataset included with this project.
